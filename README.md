# Blackletterpress - Assignment

Project gồm:
- `register.html`: trang đăng ký nhận thông tin.
- `media.html`: trang đa phương tiện sử dụng các thẻ HTML5 semantic và media.
- `index.html`: trang điều hướng đơn giản.
- `css/style.css`: CSS dùng chung cho cả hai trang.

## Chạy project
Mở `index.html` bằng trình duyệt, hoặc dùng Live Server trong VS Code.

## Đẩy lên GitHub
```bash
cd duong-dan-toi-project
git init
git add .
git commit -m "Create register and media pages"
git branch -M main
git remote add origin https://github.com/TEN_GITHUB/TEN_REPOSITORY.git
git push -u origin main
```

Sau khi tạo repository trên GitHub, thay URL ở lệnh `git remote add origin` bằng URL repository của bạn.
